# Dungeon Forge

Özgün, zar tabanlı fantastik rol yapma oyunu.

## İlk prototip
- Karakter oluşturma
- 4 özgün sınıf
- 4 köken
- STR / DEX / CON / INT / WIS / CHA istatistikleri
- d20 yetenek kontrolleri
- Tur bazlı savaş
- Can, mana, zırh ve altın
- Rastgele dungeon karşılaşmaları
- Seviye ve XP sistemi

## Çalıştırma
`index.html` dosyasını tarayıcıda aç.

Bu proje Dungeons & Dragons'dan masaüstü FRP hissi açısından esinlenir; evren, karakterler ve oyun içeriği özgündür.
